How the work goes

Start with the constraint

Every project has one thing it genuinely cannot afford to get wrong. We find it in the first week, and everything else arranges itself around it.

Build it, don't deck it

Work is reviewed in the browser, on real devices, with real content. Slides are for recapping decisions, not making them.

Leave it maintainable

You get the files, the reasoning, and a system your team can extend without calling me. That is the point of hiring a designer once.
